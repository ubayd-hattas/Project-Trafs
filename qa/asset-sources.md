# Image and content provenance

The principal-demo redesign uses real Trafalgar imagery only. No stock or generated photographs were added.

- campus.webp and entrance.webp: existing repository assembly.webp and hero.webp; reviewed as actual exterior photographs. Dates unknown; no current-date claim.
- salwa-southgate.webp: existing principal.webp, resized to 600px. Name and Principal role supplied by the project owner.
- anwar-samsodien.webp: supplied context portrait, retained at its native 150px width and displayed at 108–120px. Name and Vice Principal role supplied by the project owner. A higher-resolution replacement would improve larger uses.
- crest.png and browser icons: existing official school crest, preserved.
- harold-cressy.webp and class-of-1969.webp: existing school archive photographs, identified in the repository and supplied anniversary CSV.
- athletics-2025.webp: https://trafalgarhighschool.co.za/wp-content/uploads/2025/03/Athletics-2025.jpg

Full-size originals were derived from the thumbnail URLs in the provided whats_happening CSV and visually reviewed. Activity images are explicitly presented as 2025 archive material. No event title, award, participant identity or current programme was inferred from a photograph.
